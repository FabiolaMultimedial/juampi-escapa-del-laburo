# Ayuda a Juampi a escapar del laburo

[🎮 Jugar](https://FabiolaMultimedial.github.io/juampi-escapa-del-laburo/)

Juego arcade de laberinto, mates y termos. Controles e instrucciones dentro del juego.

El repositorio contiene la versión compilada lista para GitHub Pages. El archivo `codigo-fuente.zip` incluye el proyecto React + TypeScript + Vite: descomprimir, ejecutar `npm install` y `npm run dev`. Para compilar: `npm run build`. Requiere Node.js 22.12 o posterior.

Exportado de Google Playground y adaptado para funcionar de manera independiente. Ver THIRD_PARTY_NOTICES.md.
